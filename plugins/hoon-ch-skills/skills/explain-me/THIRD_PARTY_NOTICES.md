# Third-party notices

Explain Me is an original integration skill built from two upstream ideas:

- ELI5 defines the audience-facing goal: a dead-simple HTML picture explainer
  with large visuals and few words.
- Archify defines the typed diagram taxonomy, validation, delivery, and browser
  evidence workflow.

Explain Me does not bundle either project's renderer, templates, examples, or
font assets.
