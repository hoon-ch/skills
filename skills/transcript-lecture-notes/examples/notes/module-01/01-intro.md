# Release Notes Basics

## TL;DR

Release notes help users understand what changed, why the change matters, and
what action they should take next.

## Why It Matters

A release note is not just a changelog copy. It turns raw changes into a
reader-facing explanation. If an update requires user action, that action should
appear near the top so it is not missed.

## Lecture Flow

The lesson defines release notes as a communication layer around product
changes. A useful note groups content into new features, fixes, and known
issues. It also keeps the original changelog available so reviewers can verify
that the article did not drop any source material.

## Key Points

- Explain what changed.
- Explain why the change matters.
- Put required user action near the top.
- Keep the original source available for review.

## Coverage Checklist
